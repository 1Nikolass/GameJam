# Не та клавиша

**Игровой джем** · Тема: «Не та клавиша» · Дедлайн: 27 сентября 2026, 17:00

## Концепция

Игра, в которой главный герой управляется «неправильными» клавишами — привычные действия совершаются не теми кнопками, которых ожидает игрок. Механика построена вокруг путаницы и переобучения: прыжок там, где ожидался удар; атака там, где ожидалось движение. Сложность растёт по мере того, как схема управления меняется прямо во время игры.

## Быстрый старт

### Что нужно установить

| Инструмент | Версия | Зачем |
|---|---|---|
| **Unity** | **6000.4.1f1** | Основной движок |
| **Git LFS** | последняя | Хранение бинарных файлов (арт, звук) |
| **Python** | 3.10+ | Нужен для MCP сервера |
| **uv / uvx** | последняя | Запуск MCP сервера (`pip install uv`) |

### Клонирование и начало работы

```powershell
# 1. Клонировать репозиторий
git clone https://github.com/1Nikolass/GameJam.git
cd GameJam

# 2. Инициализировать Git LFS (один раз на машине)
git lfs install

# 3. Перейти на свою ветку (они уже созданы на сервере)
git checkout dev-nikolas

# 4. Открыть проект в Unity 6000.4.1f1:
#    Unity Hub -> Add -> Add project from disk -> папка GameJam
```

> Есть ещё один обязательный шаг — подключение Unity-мерджера сцен.
> Он описан в [CONTRIBUTING.md](CONTRIBUTING.md#4-подключить-unity-мерджер-сцен--обязательно).
> Без него конфликт в сцене ломает её насовсем.

## Правила командной работы

Полная инструкция — **[CONTRIBUTING.md](CONTRIBUTING.md)**. Прочитай её перед первым коммитом.

Коротко самое важное:

- **`main` — всегда рабочая сборка.** Напрямую в неё пушит только Nil.
- Nikolass и Danya вливают свои ветки в `main` **через Pull Request**, который одобряет Nil.
- Каждое утро подтягивай `main` к себе в ветку. Свою ветку пушь часто — хоть каждый час.
- **Перед правкой любого `.unity`-файла предупреди команду в чате.** Одновременная правка сцены двумя людьми = конфликт, который нормально не разрешается.
- `Asset Serialization Mode = Force Text` — уже включено в репозитории, приедет само. Проверить: `Edit → Project Settings → Editor → Asset Serialization`.
- Формат коммита: `feat: добавил систему управления` / `fix: починил прыжок`.

## MCP for Unity (CoplayDev)

Пакет `com.coplaydev.unity-mcp` уже добавлен в `Packages/manifest.json`.

Для использования MCP сервера нужен **Python + uv**:

```bash
# Установить uv (если ещё нет)
pip install uv
# или через curl: curl -LsSf https://astral.sh/uv/install.sh | sh

# Запустить MCP сервер
uvx --from mcpforunityserver==9.7.3 mcp-for-unity
```

После установки пакета в Unity откройте `Window → MCP For Unity → Server Window` и запустите сервер.
